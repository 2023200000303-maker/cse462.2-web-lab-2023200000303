About the Tech Event

Welcome to the official portal for the SEU Tech Fest. This interactive event gathers computer science students, student developers, and technology experts to share practical programming experience and showcase software projects.

Special Announcement: Registration is 100% free for all active Southeast University students!

For more details and university updates, visit the Southeast University Official Portal.

Key Learning Topics

  • Relational Database Architecture & Querying
  • Version Control Systems & Git Workflows

Participation Steps

  1. Fill out the student registration form provided below.
  2. Receive your registration confirmation email and ID pass.
  3. Join the orientation session on the event day.
